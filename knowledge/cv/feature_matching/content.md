# 特征匹配

## 任务定义

给定两张图像，检测局部特征点，并建立它们之间的对应关系。特征匹配是三维重建、图像拼接、视觉定位等任务的基础。

## 核心流程

1. **关键点检测**：在图像中寻找稳定、可重复的定位点
2. **描述子计算**：为每个关键点生成具有区分度的向量
3. **描述子匹配**：在两张图之间寻找描述子最相似的点对
4. **匹配筛选**：使用距离阈值或 Lowe ratio test 去除歧义匹配
5. **RANSAC 几何一致性验证**：估计单应矩阵并剔除外点

## 输入输出

- **输入**：两张 RGB/BGR 图像（Image A、Image B）
- **输出**：匹配可视化图、关键点数量、匹配数量、内点数量（若使用 RANSAC）

## SIFT

SIFT（Scale-Invariant Feature Transform）在尺度空间中寻找 DoG 极值点作为关键点，并为每个点分配主方向，生成 128 维梯度直方图描述子。它对尺度变化、旋转和部分光照变化具有鲁棒性。

## ORB

ORB 结合 FAST 关键点与 BRIEF 描述子，并通过方向统计实现旋转不变性。相比 SIFT，ORB 计算更快、适合实时应用，但描述子区分度通常略低。

## RANSAC

直接匹配会产生误匹配（外点）。RANSAC 随机采样最小点集估计单应矩阵，统计内点数量，迭代选取最佳模型，从而保留几何一致的匹配。

## 常见方法

| 方法 | 特点 |
|------|------|
| SIFT | 经典、鲁棒、需 opencv-contrib |
| ORB | 快速、免费、适合工程 |
| RANSAC Homography | 在匹配基础上做几何验证 |

## 学习目标

- 理解关键点、描述子、匹配器的基本概念
- 对比 SIFT 与 ORB 的速度与匹配质量
- 理解 RANSAC 如何提升匹配可靠性

## 学习建议

先理解 SIFT，再学习 ORB 的工程优化，最后理解 RANSAC 如何做几何验证。
